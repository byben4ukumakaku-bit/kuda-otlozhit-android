# Куда отложить — Android

Это исходный проект для отдельного Android APK. Экран и расчёт взяты из веб-приложения; все файлы интерфейса включены в проект. Интернет для работы приложения не нужен. Суммы сохраняются локально на телефоне. Данные из веб-версии автоматически не переносятся.

## Получить APK в Android Studio

1. Распакуйте архив на компьютер и откройте папку проекта в Android Studio: **File → New → Import Project**.
2. Дождитесь синхронизации Gradle и установки предложенных Android SDK-компонентов. Проект использует JDK 17, Gradle 8.13, Android Gradle Plugin 8.13.2 и SDK 36.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Готовый файл будет в `app/build/outputs/apk/debug/app-debug.apk`.
4. Передайте этот APK на Android и установите. Для публикации или обновлений с сохранением данных используйте постоянный ключ подписи вместо отладочного.

**Важно:** архив сам по себе не APK. Его нужно собрать с Android SDK. ИИ-модель не подключена: приложение рассчитывает суммы по приоритетам и срокам.

## Сборка без Android Studio

В проект добавлен `.github/workflows/build-apk.yml`. После загрузки файлов в репозиторий GitHub с веткой `main` GitHub Actions соберёт отладочный APK и приложит его как артефакт `KudaOtlozhit-APK` к запуску workflow. Для установки на свой телефон такого APK достаточно; это не релиз для магазина приложений.
